# Feature spec template

Copy this template, fill it in, and pass the result to the plugin as
`featureBrief` (or paste the whole file into the chat).

## 1. One-line brief

> *"<verb> <object> so that <user-job>."*

## 2. Audience

Who lands on this prototype first? One sentence.

## 3. Screens (3–6)

List each screen in the order a user reaches it. For each, write one
phrase describing the job done on that screen.

1. **<screen 1>** — <job>
2. **<screen 2>** — <job>
3. **<screen 3>** — <job>
4. *(optional)* **<screen 4>** — <job>

## 4. Action verbs the prototype must make real

Bullet every action verb the user will perform. The agent wires each
one to a working control with real states.

- <verb 1> — <expected behavior>
- <verb 2> — <expected behavior>
- <verb 3> — <expected behavior>

## 5. Single decisive flourish

One sentence describing the one moment that should feel polished and
deliberate — not three flourishes, one.

## 6. Things to avoid

Specific anti-patterns this prototype must not adopt (e.g. purple
gradients, generic emoji feature rows, single-page scroll).
